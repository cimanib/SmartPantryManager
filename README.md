App Name : Smart Pantry Manager

The Smart Pantry Manager application was developed to provide users with a simple mobile solution for managing pantry ingredients and discovering recipes based on their available food items.

Target Users
The application is intended primarily for individuals and households who want to keep track of their pantry ingredients, quantities and expiry dates.
It can be particularly useful for users who want to:
•	Keep a digital record of pantry items. 
•	Monitor ingredient quantities. 
•	Track expiry dates. 
•	Add, edit and delete pantry items. 
•	View a collection of recipes. 
•	View recipe ingredients and preparation instructions. 
•	Receive recipe suggestions based on pantry information. 
•	Configure application preferences.
